GrandGridStudio Review UI — Phase 1

Operational, dense, keyboard-driven review queue. All product facts come from the API; the shared contract is the only source of types.

Scope (Phase 1 only)





Password gate

916 player from latest completed render mp4_url



Inspector tabs transcript  on-screen copy  validation



Approve  Needs Fix  Reject (Needs Fix + Reject require feedback)



Keyboard shortcuts A, N, R, J, K



Loading  empty  error  submitting  success  failure states

Out of scope render & exported endpoints surface no UI (typed client methods exist but unused), listings, templates, voices, music are wired in the client but not consumed yet.

API client (srclibapi-client.ts)

Thin typed wrapper





getVariants(status='preview-ready') PromiseVariant[]



postDecision(id, { decision, reason }) PromiseDecision



requestRender(id), markExported(id) — defined but not wired to UI



getListingsgetTemplatesgetVoicesgetMusic — defined for completeness

GETs send no token. POSTs send Content-Type applicationjson + x-review-token. On non-2xx, throws Error(message) with the response body text so the UI can surface the exact message.

Auth gate





On submit, compare entered value to VITE_REVIEW_UI_PASSWORD.



On match, set sessionStorage[review-ui-auth]=1 and render the queue.



A small Lock button in the header clears it. This is a UX gate, not security.

Data flow





useQuery(['variants','preview-ready'], () = api.getVariants('preview-ready')) with staleTime 15s.



Selected variant stored in URL search param v=id via Route.useSearch() + useNavigate (so refresh keeps state). Default selection first item.



useMutation for decisions; on success queryClient.invalidateQueries(['variants','preview-ready']) and toast.



Never show approved unless backend confirms optimistic UI is disabled; the row reflects only what the refetched list returns.

Inspector





Tabs Transcript (narration_script_json), On-screen (on_screen_copy_json), Validation (validation_json).



JsonView renders pretty-printed JSON in a pre with monospace + scroll; for arrays of {t, text} style transcripts it falls back to a table-ish list. No assumptions about exact shape — unknown from the contract is honored.

Decision bar





Three buttons with lucide icons Check, AlertTriangle, X.



Approve submits immediately.



Needs Fix  Reject reveals a Textarea; submit disabled until non-empty trimmed text. Zod validates reason length 1–2000.



States idle → submitting (button spinner, all disabled) → success (toast, refetch) → failure (toast with exact API error message; form stays).

Keyboard shortcuts (srclibkeyboard.ts)

Global listener; ignored when focus is in an inputtextarea unless explicitly allowed





J next variant, K previous (wrap)



A approve current



R reject current (focuses reason textarea, requires confirm via Enter)



N focus Needs Fix textarea
