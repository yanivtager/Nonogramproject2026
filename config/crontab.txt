# GrandGridStudio — Automated Marketing Cron Schedule
# All times in UTC (Israel is UTC+3 in summer, UTC+2 in winter)
#
# Content posting: 3x/week with timezone rotation
#   Tue 08:00 UTC = 11:00 Israel (Europe morning audience)
#   Thu 16:00 UTC = 19:00 Israel (USA morning audience)
#   Sat 12:00 UTC = 15:00 Israel (Asia/AU evening audience)
#
# Message sweeps: daily (morning + afternoon)
# Daily summary: nightly

BASH_ENV=/home/grandgrid/Nonogramproject2026/.env
